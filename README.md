# 墨页

墨页是一款用 Rust 与 GPUI Kit 编写的本地电子书阅读器。正文、目录和批注都在原生窗口内绘制，可以离线阅读。

## 打开和构建

macOS Apple 芯片版位于 `dist/墨页.app`，也可解压 `dist/墨页-macOS-arm64.zip` 后在 Finder 双击打开。打开后进入书库，点击书籍即可开始或继续阅读。首次启动可以打开带脚注的试读《雾岸来信》。

用 Rust 与 Xcode Command Line Tools 重新构建：

```sh
cargo run --locked
./scripts/build-macos.sh
cargo test --locked
```

也可以在命令行里直接指定一本书，例如 `cargo run --locked -- "/path/to/book.epub"`。

## 阅读和批注

- 顶栏的「书库」和「阅读」可自由切换。阅读页左栏显示当前书籍的目录，回到书库时会保存阅读位置。
- 在书库右上角用「导入书籍」选择文件，或把文件拖到窗口。TXT 支持 UTF-8、带 BOM 的 UTF-16、GB18030（含常见 GBK 文本）和自动识别常见章节标题。EPUB 支持 EPUB 2/3 目录、书内链接、常见行内样式、封面和 PNG、JPEG、GIF、WebP 插图。
- 拖选正文后可选三种颜色划线、添加备注或复制原文。「我的批注」可回到原文、修改备注和颜色，或删除批注。
- 点击正文里的注标，脚注、尾注和词注会在原文旁弹出。支持跨文件注释、旧式锚点、图片注标、缩写释义和 Ruby 读音。正文中的夹批、旁批、回评和校记可随原文显示，兼容常见的 EPUB 标记和文字颜色。
- 阅读工具栏的书签图标可添加或移除当前位置的书签。右侧「书签」页可跳回保存位置，也可移除书签。
- 在「阅读设置 → 阅读方式」切换滚动、单页和双页。单页和双页会随窗口和字号重排，底栏显示本章页码。用底栏按钮、左右方向键、空格或 Page Up / Page Down 前后翻页。双页模式每次翻一组，每章从左页开始。
- 滚动模式下，左右方向键切换章节，空格和 Page Up / Page Down 滚动。⌘O 导入，⌘L 在书库与阅读间切换，⌘+ / ⌘− 调字号，⌘C 复制选中正文，⌘D 添加或移除当前位置书签。「阅读设置」有纸色、明亮和夜间三种配色。

导入的书籍副本、阅读位置、偏好、书签和个人批注保存在 `~/Library/Application Support/Moye Reader/`。应用按文件内容去重，批注使用章节内的文本位置，因此切换配色、字号和窗口宽度后仍能定位。正文、目录和书库列表按视口渲染，图像按需在后台解码。

EPUB 以重排正文为主，当前兼容范围是无 DRM 的文本型电子书。复杂 CSS、固定版式和多媒体按可提取内容降级显示。
